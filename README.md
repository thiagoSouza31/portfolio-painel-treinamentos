# Portfólio · Painel de Treinamentos

Portfólio do projeto de estágio **Painel de Treinamentos** (Prontosoft · UniFil · 2026).

## Estrutura

```
index.html          página única com as 7 seções
style.css           estilos
script.js           abas, imagem ampliada e menu ativo
img/diagramas/      diagramas UML, DER e BPMN
img/telas/          capturas de tela do sistema (adicionar)
docs/               PDFs do relatório e dos artefatos RUP
```

## O que falta preencher

No `index.html`: link do repositório (`SEU-USUARIO/SEU-REPOSITORIO`), matrícula, data de entrega, vídeo do YouTube e status dos casos de uso. Se tiver prints do sistema implementado, adicione em `img/telas/` e inclua novos cartões na seção 5.

## Publicar no GitHub Pages

1. Crie um repositório público (ex.: `portfolio-painel-treinamentos`).
2. Envie todos os arquivos desta pasta para a branch `main`.
3. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. O site fica em `https://SEU-USUARIO.github.io/portfolio-painel-treinamentos/`.
